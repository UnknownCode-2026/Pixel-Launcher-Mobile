พอImport project ไปที่Android Studioแล้วต้องไปตังค่าApiที่Config.javaเพืือเชื่อมต่อกับเซิฟเวอร์Api
ในซอสตั้งPathเกมไว้ที่storage/emulated/0/Android/sampapk.comหากไม่ได้ใช้sampapk dx ก็สามารถเปลี่ยนได้เ เช่นstorage/emulated/0/Android/leakapk.com
และเวลาอัพมอดควรนำมอดที่เพิ่มมาใหม่ไปยัดลงไฟล์ตัวเกมหลักด้วยแล้วก็เปลี่ยนเลขเวอร์ชั่นver.iniให้เป็นล่าสุด ทำแบบนี้ทุกครั้งที่อัพมอดเพราะคนที่เล่นใหม่หรือโหลดใหม่จะได้
ไม่ต้องมารออัพคือโหลดที่เดียวให้มันเสร็จไปเลย Apkก็เช่นกันเมื่อมีการอัพควรเปลี่ยนในapk.iniให้เป็นล่าสุด ver.ini/apk.iniอยู่ในตัวเกมstorage/emulated/0/Android/sampapk.com/data/
